# 境界突破遞增加成系統

## ✨ 升級後的系統

現在突破獲得的屬性加成會**隨著境界等級遞增**！越高境界突破，獲得的屬性越多！

## 📊 加成公式

### 基礎加成
- 攻擊力: 2
- 防禦力: 1
- 最大血量: 20

### 境界加成倍率
```
倍率 = 1 + Math.floor(境界等級 / 5) × 0.5
```

**每 5 級境界，加成提升 50%！**

## 💡 設計理念

### 為什麼要遞增？
1. **後期更有成就感**: 高境界突破獲得更多獎勵
2. **符合修仙邏輯**: 境界越高，每次突破的質變越大
3. **平衡遊戲節奏**: 前期穩定成長，後期爆發式提升
4. **鼓勵長期遊玩**: 越玩越強，不會感到乏味

### 平衡考量
- **前期**: 穩定的小幅成長（+2/+1/+20）
- **中期**: 開始感受到加速（+3~5）
- **後期**: 顯著的屬性提升（+10+）

## 🔢 數學分析

### 境界 1 → 50 的總成長
```
前期 (1-5):   4次 × 2攻擊 = 8
中期 (5-20):  15次 × 平均3.5 = 52.5
後期 (20-50): 30次 × 平均8 = 240

總攻擊力: 10 + 300+ ≈ 310+
```

### 與固定加成對比
```
固定加成 (每次+2):
境界 50 = 10 + 49×2 = 108 攻擊

遞增加成:
境界 50 = 10 + 300+ = 310+ 攻擊

差距: 3倍！
```

## ⚙️ 調整參數

如果想修改成長速度，可以調整 `main.js` 中的參數：

### 修改基礎加成
```javascript
const baseAttack = 2;   // 改這裡：基礎攻擊加成
const baseDefense = 1;  // 改這裡：基礎防禦加成
const baseHp = 20;      // 改這裡：基礎血量加成
```

### 修改遞增速度
```javascript
// 當前：每 5 級 +50%
const realmBonus = 1 + Math.floor(gameState.realmLevel / 5) * 0.5;

// 更快：每 3 級 +50%
const realmBonus = 1 + Math.floor(gameState.realmLevel / 3) * 0.5;

// 更慢：每 10 級 +50%
const realmBonus = 1 + Math.floor(gameState.realmLevel / 10) * 0.5;

// 更激進：每 5 級 +100%
const realmBonus = 1 + Math.floor(gameState.realmLevel / 5) * 1.0;
```
