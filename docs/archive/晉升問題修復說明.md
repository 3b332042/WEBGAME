# 晉升問題修復說明

## 問題描述
用戶反映在榮譽堂挑戰成功後，沒有正確晉升。

## 已實施的修復

### 1. 增強調試日誌 (`123.html`)
在 `handleVictory()` 函數中添加了詳細的 console.log：

```javascript
console.log("=== Victory Debug ===");
console.log("Boss ID:", bossId);
console.log("Enemy Unit:", enemyUnit);
console.log("Target Rank:", targetRank);
console.log("Current Rank:", currentRank);
console.log("Promoting from", currentRank, "to", targetRank);
console.log("Save result:", saved);
console.log("Verified factionRank in localStorage:", parsed.factionRank);
```

### 2. 確保狀態正確保存
- 添加 `GameStateManager.sync()` 確保同步到 window.gameState
- 添加 localStorage 驗證步驟
- 確保在保存前載入最新狀態

### 3. 創建測試工具
創建了 `test-promotion.html` 用於測試和調試晉升系統。

## 使用測試工具

### 打開測試頁面
在瀏覽器中打開：`test-promotion.html`

### 功能說明
1. **當前狀態** - 顯示當前的 factionRank、factionRep、factionContrib
2. **測試晉升** - 直接設定階級並驗證保存
3. **測試日誌** - 查看詳細的操作記錄

### 測試步驟
1. 打開 `test-promotion.html`
2. 查看「當前狀態」確認初始值
3. 點擊「晉升到 Rank 1」等按鈕測試
4. 查看日誌確認保存是否成功
5. 刷新頁面，確認階級是否保留

## 調試步驟

### 在實際遊戲中調試
1. 打開瀏覽器開發者工具 (F12)
2. 切換到 Console 標籤
3. 進入榮譽堂挑戰 NPC
4. 戰鬥勝利後查看 Console 輸出

### 關鍵檢查點
查看以下日誌輸出：

```
=== Victory Debug ===
Boss ID: npc_inner          // 確認 Boss ID 正確
Target Rank: 1              // 確認目標階級正確
Current Rank: 0             // 確認當前階級
Promoting from 0 to 1       // 確認晉升邏輯觸發
Save result: true           // 確認保存成功
Verified factionRank: 1     // 確認 localStorage 中的值正確
```

## 可能的問題原因

### 1. Boss ID 不正確
**症狀**: Console 顯示 "Boss not in promotion map"
**原因**: `enemyUnit.id` 沒有正確設定
**解決**: 檢查 `BOSS.js` 和初始化邏輯

### 2. GameStateManager 未定義
**症狀**: Console 顯示 "GameStateManager is undefined"
**原因**: `state.js` 未正確載入
**解決**: 確認 script 載入順序

### 3. 保存失敗
**症狀**: "Save result: false"
**原因**: localStorage 可能被禁用或已滿
**解決**: 檢查瀏覽器設定

### 4. 階級已達到或超過目標
**症狀**: 顯示「您已是 Rank X，無需晉升」
**原因**: `factionRank` 已經 >= 目標階級
**解決**: 這是正常行為，不是錯誤
