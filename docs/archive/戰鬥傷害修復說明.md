## 📊 傷害計算公式

### 玩家攻擊敵人
```
基礎傷害 = 攻擊力 × 防禦減傷 × 境界加成 × 屬性相剋 × 技能倍率
暴擊傷害 = 基礎傷害 × (1 + 暴擊傷害加成)
最終傷害 = 暴擊 ? 暴擊傷害 : 基礎傷害
```

### 敵人攻擊玩家
```
基礎傷害 = 敵人攻擊力 × 玩家防禦減傷
暴擊傷害 = 基礎傷害 × (1 + 敵人暴擊傷害)
最終傷害 = 暴擊 ? 暴擊傷害 : 基礎傷害
```

### 防禦減傷公式
```
減傷倍率 = 1 - (防禦 / (防禦 + 100))
最低保留 20% 傷害（不會完全免疫）
```

## 🎮 使用的數值來源

| 數值 | 玩家來源 | 敵人來源 |
|------|---------|---------|
| 攻擊力 | `state.js` → `gameState.attack` | `BOSS.js` → `BOSS_DB[id].attack` |
| 防禦力 | `state.js` → `gameState.defense` | `BOSS.js` → `BOSS_DB[id].defense` |
| 暴擊率 | `state.js` → `gameState.critRate` | `BOSS.js` → `BOSS_DB[id].critRate` |
| 暴擊傷害 | `state.js` → `gameState.critDamage` | `BOSS.js` → `BOSS_DB[id].critDamage` |
| 最大血量 | `state.js` → `gameState.maxHp` | `BOSS.js` → `BOSS_DB[id].maxHp` |

### 傷害計算示例
```
玩家攻擊宗主:
基礎 = 10 × 0.67 × 1.0 × 1.0 × 1.0 = 6.7 ≈ 7
暴擊 = 7 × 1.5 = 10 (5% 機率)

宗主攻擊玩家:
基礎 = 100 × 0.95 × 1.0 = 95
暴擊 = 95 × 2.0 = 190 (10% 機率)
```
