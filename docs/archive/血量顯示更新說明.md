# 戰鬥場景血量顯示更新

## 更新內容

在 `123.html` 戰鬥場景中添加了實際血量數值顯示。

## 改進

### 修改前
- ❌ 只顯示百分比血條
- ❌ 使用固定的 100 HP
- ❌ 無法看到實際血量數值

### 修改後
- ✅ 顯示實際血量數值（如 "800/800"）
- ✅ 使用角色和敵人的真實最大血量
- ✅ 血條和數值同步更新

## 技術實現

### 1. HTML 結構
添加了血量文字顯示元素：
```html
<div class="hp-text" id="player-hp-text">100/100</div>
<div class="hp-text" id="enemy-hp-text">100/100</div>
```

### 2. CSS 樣式
```css
.hp-text {
    position: absolute;
    text-align: center;
    font-size: 13px;
    font-weight: bold;
    color: #f5e5b6;  /* 金色 */
    text-shadow: 0 0 4px rgba(0, 0, 0, 0.8);
}
```

### 3. JavaScript 邏輯

#### 使用實際血量
```javascript
let enemyHP = enemyUnit ? enemyUnit.maxHp : 100;
let playerHP = playerUnit ? playerUnit.maxHp : 100;
const enemyMaxHP = enemyHP;
const playerMaxHP = playerHP;
```

#### updateHP() 函數
```javascript
function updateHP() {
    // 更新血條百分比
    const enemyPercent = (enemyHP / enemyMaxHP) * 100;
    const playerPercent = (playerHP / playerMaxHP) * 100;
    
    document.getElementById("ehp").style.width = enemyPercent + "%";
    document.getElementById("php").style.width = playerPercent + "%";

    // 更新血量文字
    document.getElementById("enemy-hp-text").textContent = 
        `${Math.max(0, Math.floor(enemyHP))}/${enemyMaxHP}`;
    document.getElementById("player-hp-text").textContent = 
        `${Math.max(0, Math.floor(playerHP))}/${playerMaxHP}`;
}
```

## 顯示效果

### 玩家血量（左側）
- 位置：玩家方塊上方
- 顏色：金色 (#f5e5b6)
- 格式：當前HP/最大HP（如 "100/100"）
- 血條：綠色

### 敵人血量（右側）
- 位置：敵人方塊上方
- 顏色：金色 (#f5e5b6)
- 格式：當前HP/最大HP（如 "800/800"）
- 血條：紅色

## 特點

✅ **動態更新** - 每次受傷或治療都會更新
✅ **實際數值** - 顯示真實的血量，不是百分比
✅ **清晰可讀** - 金色文字帶陰影，易於閱讀
✅ **自動適配** - 根據角色和敵人的實際最大血量顯示

## 示例

- 玩家 100 HP，受到 30 傷害 → 顯示 "70/100"
- 敵人 800 HP，受到 250 傷害 → 顯示 "550/800"
- 玩家治療 20 HP → 顯示 "90/100"
