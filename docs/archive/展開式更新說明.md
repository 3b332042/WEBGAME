# 展開式欄位更新說明

## 更新內容

已將 `index.html` 左側面板的所有資訊區塊改為可展開/收合的形式：

### 改為展開式的區塊
1. **角色資訊** - 預設展開
   - 姓名、年齡、壽元、境界

2. **屬性** - 預設展開
   - 真氣、悟性、氣運、靈根、心境、功法

3. **戰鬥屬性** - 預設收合
   - 攻擊力、防禦力、暴擊率、暴擊傷害、血量、屬性攻擊、戰力

4. **資源** - 預設展開
   - 靈石

5. **勢力** - 預設展開
   - 所屬勢力、聲望、位階、前往宗門按鈕

## 視覺特點

### 展開式區塊樣式
- **邊框**: 金棕色半透明邊框
- **背景**: 微妙的漸層背景
- **陰影**: 多層陰影營造立體感
- **懸停效果**: 邊框和陰影增強

### 標題樣式
- **字體**: 15px，金色 (#f5e5b6)
- **箭頭**: 自定義金色箭頭 (▸)
- **動畫**: 展開時箭頭旋轉 90 度
- **懸停**: 文字變亮

### 互動動畫
- **展開動畫**: 淡入效果 (0.2s)
- **箭頭旋轉**: 平滑的 cubic-bezier 緩動
- **懸停效果**: 邊框和陰影過渡

## 優點

✅ **節省空間**: 不常用的資訊可以收合
✅ **更整潔**: 界面更簡潔有序
✅ **易於使用**: 點擊即可展開/收合
✅ **保持功能**: 所有功能完全保留
✅ **視覺一致**: 與整體風格統一

## 預設狀態

- **展開**: 角色資訊、屬性、資源、勢力
- **收合**: 戰鬥屬性

用戶可以根據需要隨時展開或收合任何區塊。

---

**技術實現**: 使用 HTML5 `<details>` 和 `<summary>` 元素，配合 CSS 動畫和過渡效果。
