# 宗門階級系統更新說明

## 更新內容

已將宗門階級系統從「聲望決定」改為「戰鬥晉升決定」。

## 修改前後對比

### 修改前（v3）
- **階級判定**: 根據 `factionRep`（聲望）自動計算階級
- **聲望作用**: 達到特定聲望值自動晉升
- **問題**: 聲望可以通過任務等方式獲得，不夠有挑戰性

### 修改後（v4）
- **階級判定**: 完全由 `factionRank` 決定（通過榮譽堂戰鬥晉升）
- **聲望作用**: 純粹作為資源，用於任務、兌換等，不影響階級
- **優點**: 階級必須通過戰鬥挑戰獲得，更有成就感

## 技術細節

### 修改的文件
- `faction.js` - 勢力系統核心邏輯

### 主要修改

#### 1. `getFactionRankIndex()` 函數
```javascript
// 修改前：根據聲望計算階級
const rep = gameState.factionRep;
const req = f.repRequired || [];
let idx = 0;
for (let i = 0; i < req.length; i++) {
    if (rep >= req[i]) idx = i;
}
return idx;

// 修改後：直接使用 factionRank
const rank = gameState.factionRank || 0;
const maxRank = (f.ranks || []).length - 1;
return Math.min(rank, maxRank);
```

#### 2. `addFactionRep()` 函數
- **移除**: 聲望變動時的自動升階檢測
- **移除**: 升階提示訊息
- **保留**: 聲望變動記錄

#### 3. 註釋更新
- 更新文件頂部說明
- 標註關鍵修改點

## 階級系統運作方式

### 階級獲得
1. 玩家在**榮譽堂**（honor-hall.html）挑戰 NPC
2. 戰鬥勝利後，`123.html` 的 `handleVictory()` 函數設定 `factionRank`
3. 系統自動更新顯示的階級名稱

### 階級對應（青雲宗為例）
| Rank | 階級名稱 | 獲得方式 |
|------|---------|---------|
| 0 | 雜役弟子 | 初始階級 |
| 1 | 外門弟子 | 戰勝「內門弟子」NPC |
| 2 | 內門弟子 | 戰勝「真傳弟子」NPC |
| 3 | 真傳弟子 | 戰勝「傳功長老」NPC |
| 4 | 執事長老 | 戰勝「護法」NPC |
| 5 | 太上長老 | 戰勝「宗主」NPC |

### 聲望的新用途
聲望現在是獨立的資源，可用於：
- 宗門任務解鎖
- 特殊物品兌換
- 權限開啟
- 其他非階級相關的功能

## 遊戲平衡

### 優點
✅ **挑戰性**: 階級必須通過實力獲得
✅ **成就感**: 每次晉升都是戰鬥勝利的證明
✅ **清晰**: 階級路線明確，不會混淆
✅ **靈活**: 聲望可以用於其他系統

### 注意事項
⚠️ 玩家必須有足夠戰力才能晉升
⚠️ 聲望不再能「買」階級
⚠️ 階級提升完全依賴戰鬥勝利

## 相關文件

- `faction.js` - 勢力系統（已修改）
- `honor-hall.html` - 榮譽堂挑戰界面
- `123.html` - 戰鬥場景，包含 `handleVictory()` 晉升邏輯
- `state.js` - 遊戲狀態，包含 `factionRank` 欄位
