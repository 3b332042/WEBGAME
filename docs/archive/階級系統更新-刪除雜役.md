# 階級系統更新 - 刪除雜役弟子

## ✨ 更新內容

刪除了「雜役弟子」階級，玩家現在一開始就是「外門弟子」！

## 📊 新的階級系統

### 青雲宗階級（5 階）

| Rank | 階級名稱 | 晉升方式 |
|------|---------|---------|
| 0 | **外門弟子** | 初始階級 |
| 1 | **內門弟子** | 挑戰內門弟子 NPC (境界 10) |
| 2 | **真傳弟子** | 挑戰真傳弟子 NPC (境界 15) |
| 3 | **執事長老** | 挑戰傳功長老 NPC (境界 20) |
| 4 | **太上長老** | 挑戰宗主 NPC (境界 30) |

### 對比舊系統

| 舊 Rank | 舊階級 | 新 Rank | 新階級 |
|---------|--------|---------|--------|
| 0 | 雜役弟子 | - | **已刪除** |
| 1 | 外門弟子 | 0 | 外門弟子 |
| 2 | 內門弟子 | 1 | 內門弟子 |
| 3 | 真傳弟子 | 2 | 真傳弟子 |
| 4 | 執事長老 | 3 | 執事長老 |
| 5 | 太上長老 | 4 | 太上長老 |

## 🔧 修改的文件

### 1. faction.js
- 刪除所有宗門的「雜役弟子」階級
- 將 `ranks` 數組從 6 個減少到 5 個
- 更新 `repRequired` 數組

### 2. 123.html
- 更新 `promotionMap` 中的階級編號
- 所有階級編號減 1

### 3. debug-tool.html
- 更新階級測試按鈕
- 現在 Rank 0 = 外門弟子

## 🎮 遊戲體驗變化

### 之前
1. 加入宗門 → 雜役弟子 (Rank 0)
2. 需要先晉升到外門弟子 (Rank 1)
3. 然後才能挑戰內門弟子

### 現在
1. 加入宗門 → **外門弟子 (Rank 0)** ✨
2. 直接可以挑戰內門弟子 NPC
3. 更快進入核心玩法

## 💡 設計理念

### 為什麼刪除雜役弟子？
1. **簡化流程**: 減少不必要的階級
2. **更快上手**: 玩家一開始就有身份
3. **符合邏輯**: 能修煉到築基的人不應該是雜役
4. **提升體驗**: 直接進入正式弟子身份

## ⚠️ 注意事項

### 對舊存檔的影響
- 如果舊存檔的 `factionRank` 是 0（雜役），會顯示為外門弟子
- 如果舊存檔的 `factionRank` 是 1-5，會自動減 1
- 建議使用 `debug-tool.html` 檢查並調整階級

### 晉升路線
```
外門弟子 (Rank 0) - 初始
    ↓ 挑戰內門弟子 (境界 10)
內門弟子 (Rank 1)
    ↓ 挑戰真傳弟子 (境界 15)
真傳弟子 (Rank 2)
    ↓ 挑戰傳功長老 (境界 20)
執事長老 (Rank 3)
    ↓ 挑戰護法 (境界 25)
太上長老 (Rank 4)
```

**注意**: 護法 NPC 不在晉升路線中，挑戰宗主才能成為太上長老！

## 🔄 如果需要調整舊存檔

使用 `debug-tool.html`:
1. 打開「階級測試」標籤
2. 選擇正確的階級
3. 點擊對應按鈕設定

或在 Console 執行：
```javascript
// 如果舊存檔是 Rank 1（舊的外門），改為 Rank 0（新的外門）
if (gameState.factionRank === 1) {
    gameState.factionRank = 0;
    GameStateManager.save();
}
```
